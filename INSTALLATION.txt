UniMeal Cafe - Installation Instructions
=========================================

SETUP GITHUB SECRETS (One-time setup):
--------------------------------------
1. Get your Expo Access Token:
   - Go to https://expo.dev/accounts/[your-account]/settings/access-tokens
   - Create a new token with "Read and write" permissions
   - Copy the token

2. Add to GitHub Secrets:
   - Go to your GitHub repository
   - Navigate to Settings > Secrets and variables > Actions
   - Click "New repository secret"
   - Name: EXPO_TOKEN
   - Value: [paste your Expo token]
   - Click "Add secret"


RELEASE NEW VERSION:
-------------------
Method 1: Manual Trigger (Recommended)
   - Go to GitHub repository > Actions tab
   - Select "Build and Release APK" workflow
   - Click "Run workflow"
   - Enter version number (e.g., 2.0.0)
   - Click "Run workflow"

Method 2: Git Tag
   - Update version in app.json and package.json
   - Commit changes: git commit -am "Bump version to 2.0.1"
   - Create tag: git tag v2.0.1
   - Push: git push && git push --tags


USER INSTALLATION:
-----------------
1. Go to GitHub repository > Releases
2. Download the latest APK file (unimeal-cafe.apk)
3. On Android device:
   - Open Settings > Security
   - Enable "Install from Unknown Sources" or "Install unknown apps"
4. Open the downloaded APK file
5. Tap "Install"
6. Launch UniMeal Cafe app


TROUBLESHOOTING:
---------------
- If build fails, check GitHub Actions logs
- Ensure EXPO_TOKEN secret is set correctly
- Verify EAS project is configured: eas build:configure
- Check app.json has correct package name and version
