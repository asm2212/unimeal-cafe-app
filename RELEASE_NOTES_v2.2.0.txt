HOW IT WORKS
------------
1. Install the app and grant notification permissions
2. Notifications start automatically
3. When a student makes a transaction:
   - Within 5 seconds, you get a notification
   - Sound plays and device vibrates
   - See student name and amount
4. Tap notification to view full details
5. Badge count shows unread transactions

REQUIREMENTS
------------
- Android 7.0 or higher (API 24+)
- Notification permissions (requested on first launch)
- Internet connection
- 200 MB free space

INSTALLATION
------------
1. Download unimeal-cafe-v2.2.0.apk
2. Enable "Install from Unknown Sources" in Settings
3. Install the APK
4. Grant notification permissions when prompted
5. Start receiving instant transaction alerts!
